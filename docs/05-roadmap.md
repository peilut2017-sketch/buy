**תנאי סיום:** כל סעיף בצ'קליסט מסומן כמאומת או כלא אפשרי, וההחלטות החוסמות נרשמו.

## שלב 1: ביקורות בטרמינל איקס

- [ ] שלד: WXT, `packages/core`, `packages/adapters/terminalx`, `packages/ui` עם טוקנים.
- [ ] Supabase: הרצת הסכמה, RLS, נתוני התחלה, סביבת פיתוח וייצור.
- [ ] מתאם טרמינל איקס: זיהוי עם כל הסימנים, וריאנטים, מחיר ומלאי, עם בדיקות מול fixtures.
- [ ] כללי זיהוי מהשרת עם גיבוי מובנה, ודיווח כשלים.
- [ ] הרשאה אופציונלית לאתר ורישום content script דינמי.
- [ ] מסך התקנה ראשונה.
- [ ] הפס בעמוד המוצר (Shadow DOM, זכוכית, כל המצבים).
- [ ] פאנל צד: סיכום, מד התאמת מידה, סינון, רשימה, "מועיל", דיווח.
- [ ] התחברות עם גוגל וקישור במייל, כינוי.
- [ ] כתיבת ביקורת: שדות לפי סוג מוצר, וריאנט ממולא, חודש רכישה בלא מאומתת, עריכה, מחיקה.
- [ ] תצוגת "נכתבה X אחרי הקנייה" וסיווג שלבים.
- [ ] אימות דרך עמוד ההזמנות, ואימות בדיעבד.
- [ ] ממתינים לביקורת בחלון התוסף.
- [ ] רמות מדרגים לפי ספירה, מגבלות קצב, זיהוי גל ביקורות בסיסי.
- [ ] דיווח, הסתרה אוטומטית, תור פיקוח בסיסי, ערעור, טופס בקשת הסרה.
- [ ] אתר: עמוד מוצר לפי מק"ט, הדבקת קישור, חשבון, ייצוא ומחיקת מידע, מדיניות פרטיות, תנאי שימוש, הצהרת נגישות.
- [ ] לוח ניהול מינימלי: חנויות (סטטוס, אחוז זיהוי, כיבוי חירום), תור פיקוח, משתמשים, יומן פעולות.
- [ ] אירועי שימוש בסיסיים.

**תנאי סיום:**
- זיהוי נכון ב-100% מ-20 עמודי מוצר אמיתיים, ובדיקות המתאם עוברות.
- הפס נטען בלי לשבור את העמוד, על עמוד בהיר וכהה, עם שם ארוך ובלי תמונה.
- אפשר להירשם, לכתוב, לערוך, למחוק, לסמן "מועיל" ולדווח, וכל מצבי השגיאה מטופלים.
- ביקורת מאומתת מקבלת תאריך רכישה ומציגה "נכתבה X אחרי הקנייה".
- אף נתון מומצא לא מוצג.

## שלב 2: מעקב והתראות

- [ ] דיווחי מחיר ומלאי מהמשתמשים, שמירת שינויים בלבד, זיהוי חריגים.

- [ ] אימות במייל: Email Worker עם DKIM, מדריך מסנן, קובץ מצורף.
- [ ] אימות לפי מספר הזמנה, אם הוחלט (החלטה 8 ב-`07-open-decisions.md`).

- [ ] עדכון ביקורת אחרי זמן ותזכורת.

**תנאי סיום:** התראה על ירידת מחיר מגיעה בכל ערוץ תוך 15 דקות מהשינוי, בלי כפילויות, ומכבדת שעות שקטות ושבת. הודעת "נשמר" מוצגת רק אחרי שמירה מוצלחת.
