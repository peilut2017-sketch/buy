# הנחיות מוכנות ל-Claude Code

להדביק אחת בכל פעם, לפי הסדר. כל אחת מתאימה לשלב ב-`docs/05-roadmap.md`.

## 1. התמצאות

```
קרא את CLAUDE.md ואת כל הקבצים בתיקייה docs. סכם לי בעברית, בקצרה, מה אתה מבין שאנחנו בונים,
מה השלב הראשון, ואילו שאלות פתוחות חוסמות אותו. אל תכתוב קוד עדיין.
```

## 2. שלב 0 — מחקר

```
התחל את שלב 0 לפי docs/06-research-checklist.md.
בדוק באתר terminalx.com כל סעיף שאפשר לבדוק בלי התחברות: מבנה מק"ט, תגיות canonical ו-og,
נתונים מובנים, נתיב התמונה, ואיך מופיעים צבעים ומידות בעמוד מוצר.
שמור 3 עמודי מוצר לדוגמה ב-tests/fixtures/terminalx/ (מסומנים כ-fixtures),
ועדכן את הממצאים בקובץ הצ'קליסט. מה שדורש התחברות (עמוד ההזמנות, מיילים) — רשום כשאלה אליי.
```

## 3. שלד הפרויקט

```
הקם את שלד הפרויקט לפי docs/03-architecture.md: WXT עם TypeScript ו-Preact ב-apps/extension,
packages/core, packages/adapters/terminalx, packages/ui עם טוקני העיצוב מ-docs/02-design-system.md.
Manifest V3, הרשאות אתרים אופציונליות בלבד. ודא שהתוסף נבנה ונטען ב-Chrome.
לפני שאתה מתחיל, הצג לי תוכנית קצרה.
```

אחר כך בנה אותם, כולל מצבי טעינה, ריק, שגיאה ומוצר שלא זוהה. בלי נתונים מומצאים.
בדוק את התוצאה על עמוד מוצר בהיר ועל עמוד כהה, ודווח מה נבדק.
